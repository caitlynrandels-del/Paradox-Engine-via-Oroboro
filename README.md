# OROBORO // PARADOX ENGINE

> **"Yes, but..."** — A recursive, real-time quantum canvas fusing biological membranes, alchemic runic states, and live MIDI instrumentation into an interactive visual matrix.

---

## Overview

**Oroboro Paradox Engine** is an experimental, single-file HTML5/JavaScript application designed to explore dynamic state-shifting, responsive organic geometry, and audio-reactive visualization. Built with zero external framework dependencies, it renders a high-performance particle ecosystem, a breathing microporous "Gore-Tex" cell membrane, and rotating arcane/atomic orbital structures directly onto an HTML5 Canvas.

Whether driven by real-time electronic drum/MIDI triggers or simple mouse interaction, the engine absorbs stardust motes, accumulates ATP/Mana, and warps its underlying Voodoo Matrix grid in real time.

---

## Core Architecture

* **The Void & Voodoo Matrix Grid:** A deep-space aesthetic (`#010409`) paired with a cyan-glowing grid that dynamically responds to macro state changes.
* **The Living Cell / Atom Core:** A dual-phase, pulsing membrane that breathes and expands upon receiving energy inputs.
* **Arcane Orbitals & Magic Runes:** Quantum rings spinning around the core, spawning Greek/alchemical character runes (`⟷`, $\alpha$, etc.) when triggered.
* **Firefly / Stardust Mote Ecosystem:** Autonomous agents floating through the void that are magnetically pulled into the core upon energy activation, fueling internal metrics.

---

## Interactive Controls

* **MIDI Integration:** Automatically attempts to hook into connected MIDI devices (such as electronic drum kits). Striking a pad triggers membrane pulses, shifts the paradox angle, and absorbs surrounding stardust.
* **Click Interaction:** Clicking anywhere on the canvas manually forces a paradox shift and injects ATP energy if no MIDI device is connected.
